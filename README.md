# Крылья на рассвете

Браузерная игра о первом полёте бабочки. Откройте кокон и соберите 18 зёрнышек пыльцы. Зёрнышки появляются по шесть, а крылья меняют цвет после каждой собранной группы. В финале луг расцветает. Таймера и штрафов нет.

## Как играть

- На телефоне коснитесь золотой звёздочки или ведите пальцем по лугу.
- На компьютере управляйте мышью, стрелками или клавишами WASD.
- Кнопка ♪ в правом верхнем углу включает звуки.

## Локальный запуск

Распакуйте архив и откройте `index.html` в браузере. Игра работает без интернета и установки зависимостей.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Распакуйте ZIP и загрузите файлы в корень репозитория. Файл `index.html` должен находиться рядом с `style.css` и `game.js`.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. Нажмите **Save**. После публикации ссылка появится в разделе **Pages**.

Графика рисуется через Canvas, звуки создаются через Web Audio. Игра учитывает системную настройку уменьшения движения.
