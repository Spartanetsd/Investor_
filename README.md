# Потік — гра про пасивний дохід

Браузерна економічна гра за мотивами класичних настільних ігор про фінансову грамотність, у реаліях України 2026 року.
Один файл `index.html`, працює офлайн, 17 професій, боти з характером, виклик дня, авторські 3D-ілюстрації.

**Грати:** відкрийте сторінку GitHub Pages цього репозиторію або сам файл `index.html`.

- Мета: щоб пасивний дохід від активів став більшим за витрати — тоді ви виходите з кола найму на трасу.
- Купуйте активи, тримайте витрати під контролем, продавайте дорого, уникайте дорогих кредитів.
- Прогрес і рекорди зберігаються у браузері пристрою.

Усі компанії й ціни вигадані. Гра не пов'язана з авторами настільних ігор, які її надихнули.
